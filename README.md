# Gestore di Job Locali

**Gestore di Job Locali** è un sistema locale per la gestione, esecuzione e monitoraggio di job.  
Permette di:

- Salvare job con nome e comando da eseguire
- Tenere traccia dello stato dei job: pendente, in esecuzione, completato o fallito
- Registrare output e errori
- Eseguire i job manualmente tramite CLI
- Espandere facilmente con un’interfaccia React futura

## Tecnologie

- Python 3
- SQLite (database locale)
- CLI (Command Line Interface)

## Obiettivo

Creare una base solida per un task manager professionale, che possa poi essere collegato a dashboard web o sistemi di automazione più complessi.
